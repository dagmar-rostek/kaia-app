# Genderhinweis

Aus Gründen der besseren Lesbarkeit wird in dieser Arbeit auf eine
durchgehend geschlechtsspezifische Mehrfachnennung verzichtet.
Personenbezogene Bezeichnungen beziehen sich, sofern aus dem jeweiligen
Kontext nichts anderes hervorgeht, auf Personen aller Geschlechter.
Diese sprachliche Vereinfachung beinhaltet keine Wertung.
